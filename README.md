# ⚠️ REPOSITORY TAKEN DOWN — VIOLATION OF COPYRIGHT & PLATFORM RULES

This repository has been **removed and archived** after review found it to be in **violation of copyright and intellectual property regulations**. A detailed breakdown of the violations is provided below.

Only this notice remains. All source files, scripts, and folders have been deleted. The `.git` history is retained for audit purposes only.

---

### Detailed Violation Report

This takedown was issued after a comprehensive review identified multiple, overlapping policy violations. This repository was not flagged for a single mistake, but for a pattern of unauthorized use of protected works:

**1. Copyright Infringement — DMCA § 512 & GitHub DMCA Policy**
This project reproduced, modified, and redistributed copyrighted code, game assets, sprites, UI elements, and other creative works without a license or written permission from the original rights holders. This includes direct copying of proprietary game logic and the creation of a Tampermonkey script that hooks into a live service, which constitutes an infringing derivative work under 17 U.S.C. § 106. Continued distribution after notice would expose the hosting platform to secondary liability, hence the immediate removal.

**2. Intellectual Property & Trademark Misuse**
The repository used protected brand names, logos, and visual trade dress — including `Rocket Goal` branding, associated imagery, and distinct UI identifiers — in a way that falsely implied affiliation or endorsement. No trademark license was obtained, violating both the rights holder's IP rights and GitHub's Trademark Policy.

**3. Software License Violation**
The codebase incorporated and re-licensed third-party and proprietary code in breach of its original terms. This includes failure to preserve copyright notices and license text (e.g., MIT), stripping attribution, and publishing derivative builds that exceed the scope of any granted license. Such actions violate the enforceable conditions of the licenses themselves.

**4. Unauthorized Derivative Work & Service Interference**
The primary artifact (`rg_hud.user.js` / ATLAS) was an unauthorized client-side modification that injects HUD elements, alters game presentation, hijacks stats, and syncs data to external Firebase/leaderboard backends. Creating and distributing a tool that reverse-engineers, intercepts, and modifies a copyrighted online service without the operator's consent violates both copyright's derivative-work right and the service's Terms of Use.

**5. Platform Terms of Service Violations**
- **GitHub Terms of Service (Section D) & Acceptable Use Policies:** Prohibits hosting or distributing content that infringes intellectual property or circumvents technical protections. The repository's core purpose — bypassing the intended game experience via script injection — falls squarely under this prohibition.
- **Rocket Goal / Game Service ToS:** Prohibits cheating, automation, scraping, data harvesting, and unauthorized clients/mods. The synced leaderboard and clan systems scraped and republished live player data.
- **Firebase / Google Cloud ToS & Tampermonkey Distribution Guidelines:** Using backend infrastructure to store and redistribute scraped copyrighted data, and distributing the script via raw GitHub URLs to evade store review, breaches both platforms' abuse policies.

**6. Distribution & Community Policy Abuse**
By distributing the script outside official channels via direct `raw.githubusercontent.com` install links and auto-update hooks, the project circumvented consent and review mechanisms intended to protect users and rights holders. This constitutes unauthorized distribution and abuse of GitHub as a CDN for infringing material.

### Action Taken

- All folders and files deleted except `README.md` and `.git/`:
  - Removed: `rg_hud.user.js`, `atlas/`, `archive/`, `firebase/`, `worker/`, `tools/`, `.github/`, `.claude/`, `.cursor/`, `LICENSE`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, and all other source files.
- Repository is no longer functional or distributable.
- Do not re-upload, fork, or redistribute the removed content without explicit written permission from the original copyright holders.

### For the Maintainer

1. Review the DMCA, GitHub Terms of Service, and all applicable licenses.
2. Remove or properly license any third-party assets before any re-publication.
3. Obtain written authorization for trademarks, game assets, and derivative works.
4. If you believe this takedown was in error, file a formal DMCA counter-notice through GitHub Support with proof of rights/license.
