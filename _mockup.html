4. Live demo — 6s auto-dismiss from top-right

Slides in from top-right. Pulse dot indicates a fresh alert. Fades out at 6.0s. If multiple opponents match in the same match, stack vertically (each 6s). One popup per opponent per match — deduped by match_id + opponent_uid.

5. Notes to the reviewer

  • Zero new reads for existing features. The hybrid cache (top 100 per mode, 24h TTL) is isolated in a new localStorage key rgHudLbCache_v1 and only consulted by this popup. Personal rank/streak/MMR display continues to use the current near-real-time path unchanged.
  • Popup gating. Everyone gets it — writing to the leaderboard already happens automatically for anyone with the script who plays a ranked match. No new opt-in needed.
  • Cache refresh. One getDocs(leaderboard where mode == X limit 100 orderBy rating desc) per mode per 24h per user. ~300 doc reads/user/day worst case; free tier is 50k/day.
  • Dedupe. If the same person is on your team in one match and against you in the next, no double-popup — key by match_id + opponent_uid.
  • Silent when nothing to say. Unranked / outside top 100 → no popup. No noise.
