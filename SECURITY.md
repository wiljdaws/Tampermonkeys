# Security policy

## Supported versions

Only the HUD and publisher on `main` are supported. Older ATLAS versions may
still run until `admin/blacklist.minVersion` is raised; they are not a
supported security surface.

## Report a vulnerability

Do **not** open a public GitHub issue, Discord channel post, or pull request
for a security problem.

Report privately using one of these:

1. [GitHub private vulnerability reporting](https://github.com/wiljdaws/Tampermonkeys/security/advisories/new)
2. A private Discord message to Pal or JesusDied4U in the
   [Championship Discord](https://discord.gg/MDz7hsrh9m)

Include the ATLAS version, what you found, and how to reproduce it. Do not
include a public proof-of-concept, exploit script, or steps that let someone
else forge stats.

We will acknowledge the report when we see it and tell you when a fix is on
`main`. Please give us time to ship before you talk about it in public.

## What this project is

ATLAS is a community userscript. The source is public. Firebase is on the
Spark free plan. Please do not treat a missing paid-tier control as a
vulnerability unless it lets a stranger write another player's row, escalate
to admin, or take over a clan they do not lead.
